# Kindle Paperwhite Desktop Monitor

引き出しに眠っている **Kindle Paperwhite** を、PC・NAS・部屋の環境を常時監視する美しい **E-ink 卓上スマートダッシュボード** へ再活用するための超軽量・完全ヘッドレスな Rust サーバーです。

Kindle の「体験型ブラウザ（Experimental WebKit）」の厳しい描画制約に合わせてゼロから設計されており、はみ出し（スクロール）のない洗練された 3×3 グリッドと、電子ペーパーならではの極めて見やすい高コントラスト表示を実現しています。

---

## 🌟 特徴

### 1. E-ink & 旧世代ブラウザに徹底最適化した UI
- **ゼロ・スクロール保証**: Kindle の画面（解像度 1072×1268 / 有効描画領域 1226×1064 px）にピクセル単位で正確に収まり、縦・横スクロールが一切発生しません。
- **高コントラスト＆白黒反転**: 紙のような白地レイアウトを基本とし、暗い部屋でも見やすい「白黒反転（ダークモード）」をワンタップで切り替え可能。
- **ゴースト除去機能**: 電子ペーパー特有の残像を除去する白黒点滅リフレッシュ機能を搭載。
- **4方向画面回転**: ボタン操作で 0° / 90° / 180° / 270° の回転に対応し、縦置き・横置き・上下逆向きのスタンド設置に対応。
- **数値スムージング**: 急激な数値変動による画面の激しいチラつきを防ぐため、移動平均（Moving Average）による滑らかな推移表示を採用。

### 2. PC スリープ自動検知 & サーバー連動リロード
- **PC スリープ待機カード**: PC がスリープまたはシャットダウンすると、ブラウザが数秒で検知して全画面の「PCスリープ中 (☾ Zzz)」カードに自動切替。PC 復帰時には自動でダッシュボードに戻ります。
- **自動アップデート検知**: サーバー側の更新・再起動時、クライアントがインスタンス ID の変化を検知して自動で画面をリロード（手動での Kindle 操作は不要です）。

### 3. 多彩なハードウェア・外部連携モニタリング
- **Windows PC**:
  - **CPU**: 使用率（履歴グラフ）、ACPI/PDH ネイティブ温度、コア数
  - **GPU (NVIDIA NVML)**: 使用率（履歴グラフ）、VRAM 使用量、温度、**ファン回転数 (RPM)**
  - **RAM**: 使用量・使用率（履歴グラフ）
  - **NETWORK**: 送受信帯域（KB/s、履歴グラフ）
  - **STORAGE**: 全ローカルドライブの使用率・空き容量バー（昇順一覧）
- **ROOM CLIMATE (SwitchBot 温湿度計)**:
  - 室温・湿度・バッテリー残量・直近 60 分間の温湿度スパークライン推移
- **NAS (Synology DS223j 等)**:
  - CPU 使用率（100 秒履歴グラフ）、RAM、ストレージ使用量、ネットワーク送受信速度、負荷平均、HDD 温度・SMART 状態
- **SYSTEM**:
  - マザーボード/システム温度、稼働時間（Uptime）、IP アドレス、画面回転・画面クリア等のコントローラー

### 4. 完全ヘッドレス & ゼロ Python
- **デスクトップ画面を汚さない**: Windows GUI サブシステム（`#![windows_subsystem = "windows"]`）でコンパイルされており、起動時に黒いコンソール窓（cmd.exe）が一瞬たりとも表示されません。
- **単一バイナリ**: 静的 HTML/CSS/JS はバイナリに内包（`include_str!`）されているため、外部ランタイム（Python、Node.js 等）不要の `.exe` 単体で動作します。
- **ローカル LAN 限定の安全設計**: プライベート LAN（`192.168.0.0/16`, `10.0.0.0/8` 等）以外のアクセスは 403 Forbidden で自動遮断。

## 🚀 クイックスタート

### 1. ビルドまたはバイナリの準備

Rust ツールチェーンが導入されている環境でリリースビルドを行います：

```powershell
cargo build --release
```

バイナリは `target/release/paperwhite-desktop-monitor.exe` に生成されます。

### 2. 設定ファイルの作成 (`config.json`)

NAS や SwitchBot 温湿度計と連携したい場合は、リポジトリルートに `config.json` を配置します（未設定項目は自動でスタンバイ表示になります）：

```json
{
  "nas": {
    "statsUrl": "http://192.168.0.12:8789/api/stats"
  },
  "switchbot": {
    "token": "YOUR_SWITCHBOT_TOKEN",
    "secret": "YOUR_SWITCHBOT_SECRET",
    "deviceId": "YOUR_DEVICE_ID",
    "deviceName": "リビング温湿度計"
  }
}
```

※ サンプルファイル [config.example.json](config.example.json) をコピーしてご利用ください。

### 3. サーバーの起動

- **手動起動**:
  `start.bat` を実行するか、PowerShell で以下を実行します：
  ```powershell
  .\target\release\paperwhite-desktop-monitor.exe
  ```
- **停止**:
  `stop.bat` を実行するとバックグラウンドのプロセスが安全に終了します。

### 4. Windows 起動時の自動常駐（スタートアップ登録）

PC 起動時に自動でバックグラウンド常駐させたい場合は、**`setup_autostart.bat`** を実行します：
- Windows の `CurrentVersion\Run` レジストリに登録され、ログオン時にコンソール画面を出さず完全バックグラウンドで自動起動します。
- 解除したい場合は **`remove_autostart.bat`** を実行してください。

## 📱 Kindle Paperwhite 側の接続手順

1. **Kindle を PC と同じ Wi-Fi（ローカルネットワーク）に接続します。**
2. **「体験型ブラウザ」を開きます**:
   - ホーム画面右上のメニューアイコン（︙）をタップし、**「体験型ブラウザ」** を選択します。
3. **ダッシュボードの URL を入力して開きます**:
   ```text
   http://<PCのIPアドレス>:28080/
   ```
   *(例: `http://192.168.0.2:28080/`)*
4. **ブックマークに保存します**:
   - 右上メニューから「このページをブックマーク」に登録しておくと、次回以降ワンタップで開けます。
5. **表示の最適化ヒント**:
   - 部屋の照明で十分明るい環境では、Kindle のフロントライトを「0」にすると、最も自然な「本物の紙のような質感」が得られます。
   - お好みに応じて画面右下のコントローラーから回転方向（縦置き・横置き）やダークモードを選択してください。
